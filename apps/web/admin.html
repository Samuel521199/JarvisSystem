    从候选到交付

    1. 在项目会话选择技能任务及排错、TDD、模块设计或代码审阅。
    2. 勾选修改副本，选择 1—4 个同目录 Python 文件及入口。
    3. 填写公开示例和本机独立验收案例，再选择当前模型或外部 Codex。
    4. 选择源码 ZIP 或可运行 PYZ 配方。Jarvis 隔离编译、运行真实工具包入口，核对差异后下载、应用或恢复。

      已选版本怎样生效？

      本页不会重启或覆盖当前服务。结束当前助手后，通过既有运行包启动器启动所选版本；普通源码托盘启动仍使用当前源码。

      python tools/runtime_releases.py start --data-dir <当前数据目录> --mode web
